# Which script produces which number

Every table, figure and quoted statistic in the manuscript, against the script
that produces it and the file it lands in. Run order is the order given in the
README; each stage depends on the ones above it.

## Tables

| Paper | Content | Produced by | Output |
|:--|:--|:--|:--|
| Table 1 | Characteristics of the two databases | `preprocess_ptbxl.py`, `preprocess_mitbih.py` | printed record and window counts, class balance |
| Table 2 | All four models on both domains, with gap CIs | `statistical_analysis.py` (deep), `classical_baseline.py` (LR, RF) | `results/statistical_analysis.json`, `results/classical_baseline.json` |
| Table 3 | Five-seed replication, forward direction | `multiseed_experiment.py` | `results/multiseed_runs.json`, `results/multiseed_summary.json` |

Table 5 has no script behind it. It restates results that appear elsewhere in
the paper, with a verdict column, and every cell traces to one of the rows
above.

## The central comparison of section 3.2

This is the result the paper is built on, so it is worth being able to check
it directly.

| Quantity | Value | Where it comes from |
|:--|:--|:--|
| AE − CNN on MIT-BIH, primary trained pair | +0.035 AUC | `cross_dataset_eval.py`, then `statistical_analysis.py` |
| DeLong test on that difference | z = −4.95, p = 7.3 × 10⁻⁷ | `statistical_analysis.py` → `results/statistical_analysis.json` |
| Implied evaluation-set standard error | 0.035 / 4.95 = 0.0071 | derived from the two numbers above |
| Same difference across five seeds | 0.011 ± 0.020, range −0.014 to +0.037 | `results/multiseed_runs.json` |
| Paired t-test across seeds | t(4) = 1.18, p = 0.30 | `multiseed_experiment.py` |
| Ratio of the two uncertainties | 0.020 / 0.0071 ≈ 2.8 | derived |

`results/multiseed_runs.json` is committed to this repository, so the second
half of that table can be recomputed in a few lines without downloading either
database:

```python
import json, numpy as np
from scipy import stats

runs = json.load(open("results/multiseed_runs.json"))
d = np.array([r["ae_mitbih"]["AUC"] - r["cnn_mitbih"]["AUC"] for r in runs])
print(d.round(3))                                   # per-seed differences
print(f"{d.mean():.3f} +/- {d.std(ddof=1):.3f}")    # 0.011 +/- 0.020
print(stats.ttest_1samp(d, 0))                      # t = 1.18, p = 0.30
```

## What is not reproducible from this repository alone

- Anything requiring the raw signals. `processed/*.npy` is not committed; it is
  regenerated by the two preprocessing scripts once the databases are
  downloaded.
- The random forest and logistic regression are fitted once, not replicated
  across seeds. Logistic regression is deterministic; the random forest is
  seeded inside `classical_baseline.py`, so it reproduces exactly, but the
  paper carries no across-seed spread for it. This is stated as a limitation in
  section 4.4 of the manuscript.
- Model checkpoints (`baseline_cnn.pt`, `autoencoder.pt`) are not committed.
  They are regenerated by the training scripts.

Per-seed score files (`results/multiseed3_scores/seed*.npz`) are not committed;
`three_db_analysis.py` needs them and they are regenerated by `multiseed_3db.py`.

The per-seed table can be checked without any database:

```python
import json, numpy as np
runs = json.load(open("results/multiseed3_runs.json"))
d = np.array([r["ae_chapman"]["AUC"] - r["cnn_chapman"]["AUC"] for r in runs])
print(d.round(3), f"{d.mean():.3f} +/- {d.std(ddof=1):.3f}")   # -0.157 +/- 0.008
```
